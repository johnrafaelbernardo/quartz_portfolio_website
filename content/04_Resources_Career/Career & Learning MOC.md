# 🎓 Career & Learning Path

## Roles in IT Security

- **Red Team (Offensive)**: Ethical Hackers, Pentest.
- **Blue Team (Defensive)**: SOC Analysts, Incident Responders.

## The Three Pillars

1. **People**: Awareness and training.
2. **Process**: Security procedures.
3. **Technology**: Tools like SIEM, EDR, WAF.

## Learning Path (Fundamentals First)

- **OS Internals**: Windows/Linux fundamentals.
- **Networking**: OSI/TCP Model, Common Protocols.
- **Programming**: PowerShell, Python, JavaScript.
- **Practice Platforms**: TryHackMe, HackTheBox, VulnHub.
