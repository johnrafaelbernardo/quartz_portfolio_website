# ⚔️ Threat Tactics & Techniques
Based on the MITRE ATT&CK Framework.

## [[Initial Access (TA0001)]]
Getting a "foot in the door."
- [[Phishing (T1566)]]: Tricking humans into opening doors.
- [[Exploit Public-Facing Application (T1190)]]: Capitalizing on software bugs (e.g., Apache, Log4j).
- [[Valid Accounts (T1078)]]: Using stolen credentials to "log in" rather than "hack in."
- [[Drive-by Compromise (T1189)]]: Gaining access when a user simply browses a website.

## [[Execution (TA0002)]]
The adversary trying to run malicious code.
- [[Command and Scripting Interpreter (T1059)]]:
	- [[PowerShell (T1059.001)]]
	- [[Windows Command Shell (T1059.003)]]
	- [[JavaScript & VBScript (T1059.007)]]
